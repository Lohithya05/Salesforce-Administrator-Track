# Salesforce Administrator Track – Day 5

## What is Lightning Experience?

Lightning Experience is the modern Salesforce user interface designed to improve productivity, user experience, and business processes. It provides a responsive design, advanced dashboards, and customizable pages.

### Benefits

- Better User Experience
- Faster Navigation
- Modern Interface
- Mobile Friendly
- Enhanced Productivity

---

# What is Lightning App Builder?

Lightning App Builder is a drag-and-drop tool that allows Salesforce Administrators to create and customize pages without writing code.

### Features

- Home Page Customization
- Record Page Customization
- App Page Creation
- Dynamic Visibility
- Reusable Components

# Enterprise Thinking Exercise

## How Lightning App Builder Improves Productivity

1. Removes unnecessary fields.
2. Simplifies page layouts.
3. Improves navigation.
4. Shows only relevant information.
5. Reduces clicks.
6. Uses dynamic visibility.
7. Displays important alerts.
8. Provides quick access to reports.
9. Improves user experience.
10. Increases employee productivity.

# Reflection

Different users perform different tasks. Students, Faculty, Placement Officers, and Administrators require different information and workflows. Customized interfaces improve efficiency, reduce confusion, and help users focus on relevant data.
