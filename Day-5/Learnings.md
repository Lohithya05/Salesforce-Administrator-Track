# Key Learnings

## Lightning Experience

Lightning Experience is Salesforce's modern user interface that improves navigation, usability, and productivity.

### Benefits

- Better UI
- Faster Workflows
- Mobile Support
- Improved Analytics

---

## Lightning App Builder

Lightning App Builder allows admins to customize pages without coding.

### Features

- Drag-and-Drop Interface
- Custom Components
- Dynamic Visibility
- Flexible Layouts

---

## Home Pages

Home Pages provide:

- Important Metrics
- Tasks
- Notifications
- Dashboards

---

## Record Pages

Record Pages display:

- Record Information
- Related Lists
- Activities
- Reports

---

## App Pages

App Pages provide:

- Custom Dashboards
- Reports
- Utility Components
- Business-Specific Information

---

## Lightning Components

Lightning Components are reusable elements used to build Lightning pages.

Examples:

- Reports
- Dashboards
- Related Lists
- Rich Text
- Charts

---

## Dynamic Visibility

Dynamic Visibility allows components to appear only when specific conditions are met.

Benefits:

- Cleaner Interface
- Better User Experience
- Improved Productivity
